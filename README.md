# GGAndy 包租代管系統

GGAndy 是一套給包租代管公司使用的 Odoo 系統，目標是把「房東、房客、物件、租金、維修、帳務」放在同一個地方管理，讓老闆可以快速知道公司目前的營運狀況。

## 這套系統在管什麼

系統主要圍繞四種角色：

- 房東：提供物件，和公司簽包租或代管合約。
- 房客：和公司簽租約，每月繳租金、管理費與押金。
- 維修廠商：處理房屋維修與採購支出。
- 公司內部人員：負責管理物件、收租、報修、結算與帳務追蹤。

主要資料會串成這條流程：

```text
房東
  ↓
房東合約
  ↓
物件 / 出租單位
  ↓
房客租約
  ↓
每月租金期次
  ↓
租金帳單 / 房東結算 / 維修與採購費用
  ↓
GGAndy帳務總表
```

## 日常商業流程

### 1. 建立物件與出租單位

每一個管理中的房子會先建立成「物件」，物件底下可以有多個出租單位，例如整層、套房、店面或車位。

物件會記錄：

- 房東是誰
- 管理人員是誰
- 管理模式是包租、代管或混合
- 地址與備註
- 底下有哪些出租單位

出租單位會記錄：

- 房號或單位名稱
- 參考月租
- 押金月數
- 目前是空房、已出租、維修中或停用

### 2. 建立房東合約

房東合約代表「公司和房東之間怎麼合作」。

目前支援兩種模式：

- 包租：公司每月固定付給房東保底租金。
- 代管：公司替房東管理出租，依實收租金扣除管理費後結算給房東。

房東合約生效後，系統會把物件的房東、管理模式與管理期間同步更新。

到了每月房東結算日，系統會自動建立房東的 Vendor Bill，避免每個月人工忘記做結算。

### 3. 建立房客租約

房客租約代表「公司和房客之間怎麼收租」。

租約會記錄：

- 租哪一個物件與單位
- 主承租人與共同承租人
- 租期開始與結束
- 每月租金
- 管理費
- 押金
- 每月繳租日

租約生效後，系統會自動建立每月租金期次。

當每一期租金到了計費開始日，系統會自動建立租金 Invoice，讓收租可以接到 Odoo 的會計流程。

### 4. 收租與帳單

每月租金會先成為「租金期次」，再由租金期次建立客戶 Invoice。

這樣可以清楚看到：

- 哪一期租金還沒開單
- 哪一期已經開單
- 哪一期已收款
- 哪一期逾期

租金期次是營運管理用的角度，Invoice 是會計與收款用的角度。

### 5. 報修與維修費用

報修單用來記錄房客或管理人員回報的維修事項。

報修單會記錄：

- 報修物件與單位
- 報修房客或通報人
- 維修類型與優先度
- 內部負責人
- 維修廠商
- 預估費用與實際費用
- 費用由公司、房東、房客或待確認負擔

這可以讓老闆知道目前有哪些維修還沒處理，以及後續費用應該歸到哪一方。

## GGandy帳務總表

「GGandy帳務」是給老闆看整體營運狀況的地方。

它用「每個物件、每個月份」整理一列資料，讓老闆可以快速看出：

- 本月租金應收多少
- 本月實際收到多少
- 本月收到多少押金
- 本月應付房東多少
- 本月已付房東多少
- 本月採購費用多少
- 本月公司員工代墊多少
- 本月現金流小計是多少

最下面會有合計，方便一眼看整體收入、支出與現金流。

目前帳務總表是第一版，重點是先把老闆最需要看的營運數字集中起來。之後如果要細分成更完整的房東月結單、維修成本明細、員工代墊報銷流程，也可以在這個架構上繼續擴充。

## Telegram 行動指揮中心

Telegram 模組是給管理員用的行動查詢工具。

管理員綁定 Telegram 後，可以用指令查詢營運摘要，例如：

- 管理物件數
- 出租中與空房數
- 本月應收、已收、未收
- 逾期租金
- 待處理維修
- 30 天內到期租約

目前它是用 Odoo 排程定期接收 Telegram 訊息，不需要另外架 webhook。

## 老闆可以怎麼看這套系統

這套系統的核心不是只記資料，而是把營運節奏自動化：

- 合約生效後，系統知道什麼時候該收房客租金。
- 租金到期時，系統自動建立房客帳單。
- 房東結算日到時，系統自動建立房東 Vendor Bill。
- 維修與採購費用可以歸到物件。
- 最後所有數字集中到 GGandy帳務總表。

也就是說，老闆不用每次從房東合約、房客租約、發票、維修單裡一筆一筆對，而是可以先看總表掌握大方向，再往下追細節。

## 開發與測試環境

目前 Docker 環境放在：

```text
docker/ggandy
```

常用服務：

- Odoo Web：http://localhost:1025
- Odoo container：`ggandy_odoo19_web`
- PostgreSQL container：`ggandy_postgres17_db`
- 開發資料庫：`ggandy_dev`

啟動方式：

```bash
docker compose -f docker/ggandy/docker-compose.yml up -d
```
